# 📊 Sales-Insight-Dashboard

## 📌 Project Overview

This project delivers a professional and interactive Power BI dashboard designed to monitor sales performance, track key business KPIs, and uncover actionable insights.

The dashboard combines clear visual storytelling with advanced analytics features such as trend analysis, Pareto distribution, and short-term forecasting to support data-driven decision-making.

---

## 🎯 Objectives

* Track and monitor key performance indicators (KPIs) such as Total Sales, Profit, and Growth
* Analyze month-over-month sales trends and performance patterns
* Identify top-performing product categories using Pareto analysis
* Evaluate regional performance through dynamic filtering
* Forecast future revenue for better planning and strategy

## 📊 Key Features

* **KPI Cards**: Total Sales, Gross Profit, Profit Margin, Monthly Sales, Growth %
* **Revenue Forecasting**: Predicts next 3 months using trend analysis
* **Pareto Chart (80/20 Rule)**: Identifies high-impact product categories
* **Month-over-Month Growth Analysis**: Combines bar and line chart for trend + % growth
* **Interactive Filters**: Region-based filtering (Mid, North, South)
* **Clean UI Design**: Business-friendly layout for quick insights

---

## 📈 Key Insights

* Sales show consistent fluctuation with noticeable peaks during certain months
* A small number of product categories contribute to the majority of revenue (Pareto principle)
* Some periods experience negative growth, highlighting potential seasonal or operational issues
* Forecast indicates stable to moderate growth in upcoming months
* Regional filtering reveals performance variations across zones
